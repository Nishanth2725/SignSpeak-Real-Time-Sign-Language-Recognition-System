How SignSpeak Works

The Technology Pipeline

SignSpeak leverages modern browser technologies and computer vision to run entirely in your web browser. This ensures maximum privacy, as your video feed never leaves your device.

1. Webcam Input
Captures real-time video via WebRTC
↓
2. Hand Landmark Detection
MediaPipe Tasks Vision extracts 21 3D landmarks per hand
↓
3. Gesture Classification
Heuristic algorithms analyze finger states and geometry
↓
4. Text & Speech Output
Words are built into sentences and spoken via Web Speech API

Prototype Limitations

This system is a prototype designed to demonstrate the feasibility of browser-based real-time gesture recognition. It currently supports a limited vocabulary of static demonstration signs (e.g., Hello, Thumbs Up, Peace/Victory, Open Palm) and is not a complete natural sign language translator (like ASL or BSL), which rely heavily on facial expressions, body movement, and temporal grammar.
